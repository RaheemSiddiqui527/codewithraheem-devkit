# Security Policy

## Supported Versions

Only the latest release of `@codewithraheem/devkit` is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

---

## Reporting a Vulnerability

The CodeWithRaheem team takes security seriously. If you discover a security vulnerability within `@codewithraheem/devkit`, please do not disclose it publicly in an open issue.

Instead, please report the vulnerability privately by opening a **GitHub Security Advisory** on the repository:
https://github.com/RaheemSiddiqui527/codewithraheem-devkit/security/advisories/new

Or contact the maintainer directly via GitHub at `@RaheemSiddiqui527`.

### What to Include in Your Report

To help us investigate and patch the issue quickly, please provide:

1. A clear description of the vulnerability.
2. A minimal reproducible code snippet (or proof of concept).
3. The potential impact of the issue (e.g. Prototype Pollution, Denial of Service, ReDoS).
4. Any proposed remediations.

We will acknowledge receipt of your vulnerability report within 48 hours and work diligently to release a patch.
